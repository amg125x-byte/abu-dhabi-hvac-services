# abu-dhabi-hvac-services

This project contains a bilingual landing page for an Abu Dhabi HVAC services business.

## Included
- Welcome section in English and Arabic
- Services section for AC repair, installation, cleaning, and emergency support
- Contact details section with placeholder phone, email, and address
- Responsive design for desktop and mobile

## Update the contact information
Replace the sample details in `index.html` with your real business information:
- Phone
- Email
- Address
- Working hours

## Run locally
Open `index.html` directly in a browser.
